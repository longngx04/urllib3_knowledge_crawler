status: done

## Scope

Generate retrieval-oriented `KBDocumentRecord` objects from normalized
`SecurityPatternRecord` values with optional `AdvisoryRecord` and `PatchRecord`
enrichment, map plan topics onto existing `KBDocumentType` values without schema
changes, deduplicate identical content, enforce a 32 KiB content limit, and atomically
export deterministic `data/kb/documents.jsonl`. Do not add pipeline CLI commands,
validation stats, or query behavior.
