## Scope

Build the GitHub/changelog vertical slice for the configured package: fetch bounded
releases and tags JSON through the Phase 2 retrieval client/raw store, fetch changelog
file content, map tags to PEP 440 versions with commit SHAs, correlate PyPI version
records with repository evidence, parse and classify changelog entries by release, and
report unresolved version/tag mappings. Do not add advisory collection, range resolution,
patch extraction, security-semantic enrichment, or new CLI pipeline commands.
