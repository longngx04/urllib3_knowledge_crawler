# C-006 — Phase 5 advisory collection and alias resolution

status: done
deps: C-005
implements: FR25, FR26, FR27, FR28

## Scope

Build the advisory collection and alias resolution vertical slice for the configured package:
fetch raw vulnerability data from OSV / GHSA through the Phase 2 retrieval client/raw store,
extract identifiers, aliases, summary, CWE, CVSS, severity, affected ranges, fixed versions,
references, and patch commits. Implement canonical ID strategy (GHSA > CVE > OSV/PYSEC),
merge explicitly linked alias clusters into single normalized AdvisoryRecords, detect and report
source conflicts / ambiguous alias clusters, and validate every record against Phase 1 models/schemas.
