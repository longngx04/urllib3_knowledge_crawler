# C-004 — Phase 3 authoritative PyPI version inventory

status: done
deps: C-003
implements: FR17, FR18, FR19, FR20

## Scope

Build one PyPI-to-JSONL vertical slice for the configured package: fetch bounded project
JSON through the Phase 2 retrieval client/raw store, normalize every parsable release
and distribution into provenance-backed Phase 1 records, report unparsable release
keys, validate project/artifact/version invariants, expose inventory statistics, and
atomically export deterministic `versions.jsonl`. Do not add GitHub correlation,
advisory/range logic, new CLI pipeline commands, or checked-in generated crawl data.
